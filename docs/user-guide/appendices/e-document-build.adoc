== このガイドのビルド

このガイドは `{guide-source-dir}/` の AsciiDoc から、日本語版 `{guide-output}` と英語版 `{guide-output-en}` の HTML を生成します。Node.js {node-min-version} 以上と npm の development dependency だけを使います。

=== 構成

[source,text]
----
docs/user-guide/
├─ index.adoc            日本語版のルート
├─ _attributes.adoc      共通 attribute
├─ chapters/             日本語版の章（01-overview … 10-troubleshooting）
│  └─ cli/               コマンドリファレンス（1 コマンド 1 ファイル）
├─ appendices/           日本語版の付録
├─ index-en.adoc         英語版のルート
├─ en/                   英語版の章と付録（同じ構成）
└─ assets/user-guide.css 両方に埋め込む stylesheet
----

=== ビルドと検証

ADK のリポジトリのルートで実行します。

[source,bash]
----
npm ci
npm run docs:build    # 生成
npm run docs:check    # 生成 + 検証
----

`docs:check` は、include 先が存在すること、ID が重複しないこと、`xref:` の参照先があること、`TODO` が残っていないこと、必須の章 ID がそろっていること、HTML が外部 stylesheet / script に依存しないことを両言語で検証します。

=== 執筆規約

* 読者がその場で必要なことだけを、短い文で書く。難しい言葉を使わない。
* 章とコマンドページには一意の ID（`[[knowledge]]`、`[[cli-init]]`）を付け、リンクは `xref:` で書く。
* コマンドページのオプションは `aidev <command> --help` と一致させる。
* 秘密情報は `<your-pat>` のような placeholder だけを書く。
* 実装されていない機能は書かない。
* 図は `[mermaid]` ブロック（Mermaid 記法）で書く。ASCII アートは使わない。ビルドが描画用の script を HTML に埋め込むので、外部依存は増えない。CLI の出力例は `[source,text]` のまま。
* 日本語版と英語版は同じ構成・同じ ID を保つ。
