== PKG 内のファイル

{project-name} が PKG の clone に置くファイルと、コミットするかどうかの一覧です。

=== コミットするもの

[cols="2,3,2",options="header"]
|===
|パス |内容 |誰が書くか

|`aidev.yaml`
|PKG の設定
|`aidev init`、人間

|`.claude/agents/*.md`, `.claude/skills/*/SKILL.md`, `.claude/settings.json`
|配布される agent・skill・hooks
|`aidev init` / `aidev apply`。チームが編集でき、新しいテンプレートとはマージされる

|`CLAUDE.md`
|Claude への共通の指示
|同上

|`.mcp.json`
|MCP サーバーの登録
|同上

|`.github/copilot-instructions.md`, `.github/agents/<agent>.agent.md`, `.github/skills/*/**`, `.github/hooks/aidev.json`, `AGENTS.md`, `.codex/hooks.json`, `.kiro/steering/ai-dev-kit.md`, `.kiro/agents/<agent>.json`, `.kiro/agents/aidev.json`
|`tools.default` に `copilot` / `codex` / `kiro` を書いたときだけ。各ツール用の指示・agent・skill・hooks
|同上。ツールを外すと次の `aidev apply` で削除（編集済みなら残る）

|`.aidev/policy.yaml`
|承認済みの書き込み権限 policy
|`aidev permission … --approve`、`aidev init`。`writable` / `agents` の追加は人間が直接編集

|`.aidev/materialized.json`
|ツール設定の記録。適用した kit のコミットと、ファイルごとのテンプレートのハッシュと適用時のハッシュ、未解消の衝突。`aidev apply` がマージの基準に、`aidev check` が判定に使う
|`aidev init` / `aidev apply`

|`.aidev/knowledge/index.md`, `overview.md`, ページ
|LLM Wiki
|knowledge-builder agent

|`.aidev/knowledge/manifest.json`, `inventory/*.json`
|Wiki の構造と進捗
|CLI のみ

|`.aidev/workflows/<name>/`
|workflow の定義と承認記録
|`aidev workflow`、人間

|`.aidev/conventions/`
|この PKG の開発規約（`index.md`、`coding.md`、`testing.md`、`review.md`）
|convention-builder agent が生成し、人間がレビューしてコミット。`## チーム決定` の下は人間だけが書く

|`.aidev/.gitignore`
|下の「コミットしないもの」を除外する
|`aidev init` / `aidev apply`
|===

`.claude/settings.local.json` は個人設定で、kit の管理外です。

=== コミットしないもの

`.aidev/.gitignore` が除外します。消しても次のコマンドで作り直されます。

[%autowidth.stretch,options="header"]
|===
|パス |内容

|`.aidev/cache/`
|remote 確認のキャッシュ、hook が覚えている前回の HEAD（`last-head.json`）と Stop hook の回数（`wiki-stop.json`）、tracking branch への publish の一時 worktree（`wiki-worktree/`）、agent に渡す仕事ファイル

|`.aidev/sync.lock`
|tracking branch への publish の lease

|`.aidev/knowledge/.cache/`
|`plan.json`（hook がセッションに渡す batch の計画）と agent の完了報告

|`.aidev/workflows/*/runs/`
|workflow の実行ログ
|===

一時的に現れるもの: `.aidev/policy.candidate.yaml`（承認すると消えます）、`.aidev/ejected.json`（`aidev eject` が書き、`aidev init` が消します）。

=== 端末側（AIDEV_HOME）

`registry.json`（登録済み PKG の一覧）と `cache/update-check.json`（kit 更新の確認結果）を置きます。kit 本体は `AIDEV_HOME` ではなく、installer を実行した clone にあります。`aidev uninstall` がどちらも消します。{project-name} 本体の開発者の端末には `developer.json` も置かれます（利用者には関係ありません）。
