== PKG 内のファイル

{project-name} が PKG の clone に置くファイルと、コミットするかどうかの一覧です。

=== コミットするもの

[cols="2,3,2",options="header"]
|===
|パス |内容 |誰が書くか

|`aidev.yaml`
|PKG の設定
|`aidev init`、人間

|`.claude/agents/*.md`, `.claude/skills/*/SKILL.md`, `.claude/settings.json`
|配布される agent・skill・hooks
|`aidev init` / `aidev sync tools`。チームが編集でき、新しいテンプレートとはマージされる

|`CLAUDE.md`
|Claude への共通の指示
|同上

|`.mcp.json`
|MCP サーバーの登録。workflow のステップの agent が使えるのは、この中で frontmatter の `mcp` か workflow の `agents.<agent>.mcp` に書いた server だけ
|PKG（ADK は配布しない。人が編集する）

|`.github/copilot-instructions.md`, `.github/agents/<agent>.agent.md`, `.github/skills/*/**`, `.github/hooks/aidev.json`, `AGENTS.md`, `.codex/hooks.json`, `.kiro/steering/ai-dev-kit.md`, `.kiro/agents/<agent>.json`, `.kiro/agents/aidev.json`
|`tools.default` に `copilot` / `codex` / `kiro` を書いたときだけ。各ツール用の指示・agent・skill・hooks
|同上。ツールを外すと次の `aidev sync tools` で削除（編集済みなら残る）

|`.aidev/policy.yaml`
|承認済みの書き込み権限 policy
|`aidev create policy --approve`、`aidev init`。`writable` の追加は人間が直接編集

|`.aidev/materialized.json`
|ツール設定の記録。適用した ADK のコミットと、ファイルごとのテンプレートのハッシュと適用時のハッシュ、未解消の衝突。`aidev sync tools` がマージの基準に、`aidev check` が判定に使う
|`aidev init` / `aidev sync tools`

|`.aidev/knowledge/index.md`, `overview.md`, ページ
|LLM Wiki
|knowledge-builder agent

|`.aidev/knowledge/manifest.json`, `inventory/*.json`
|Wiki の構造と進捗
|CLI のみ

|`.aidev/workflows/<name>/workflow.yaml`
|workflow の定義。`origin/main` にあるものと同じときだけ実行できる
|`aidev create workflow`、人間。`aidev submit workflow` が PR にする

|`.aidev/agents/<name>.md`, `.aidev/skills/<name>/SKILL.md`
|この PKG 固有の agent と skill。agent は workflow のステップから、skill は agent の frontmatter の `skills` から名前で参照し、ADK 同梱の同名のものより優先される。agent の frontmatter は、その agent が使える skill・ツール・MCP server・サブエージェントも決める（workflow の `agents:` で足せる）。agent は `until.agent` やサブエージェントとしても参照される
|`aidev create workflow --describe`（workflow-creator）、対話中の AI、人間。workflow と一緒に PR に入る

|`.aidev/estimates/`
|費用の見積もりの記録。`records/<name>-<run id>.json`（実行ごとの見積もりと実際の費用）、`priors.json` と `notes.md`（振り返りの結果）、`judgments/<name>.json`（`aidev estimate --ai` の判断）（xref:cli-estimate[aidev estimate]）
|`aidev run workflow`（実行の worktree に書き、pull-request step が PR に入れる）、`aidev estimate`

|`.aidev/conventions/`
|この PKG の開発規約（`index.md`、`coding.md`、`testing.md`、`review.md`）
|PKG の workflow（規約を書く agent）が生成し、人間がレビューしてコミット。`## チーム決定` の下は人間だけが書く

|`.aidev/.gitignore`
|下の「コミットしないもの」を除外する
|`aidev init` / `aidev sync tools`
|===

`.claude/settings.local.json` は個人設定で、ADK の管理外です。

=== コミットしないもの

`.aidev/.gitignore` が除外します。消しても次のコマンドで作り直されます。

[%autowidth.stretch,options="header"]
|===
|パス |内容

|`.aidev/cache/`
|remote 確認のキャッシュ、hook が覚えている前回の HEAD（`last-head.json`）と Stop hook の回数（`wiki-stop.json`）、tracking branch への publish の一時 worktree（`wiki-worktree/`）、agent に渡す仕事ファイル、`aidev modify` の変更前のファイルと記録（`modify/`）、`aidev submit` の PR 本文（`submit/<name>.md`）

|`.aidev/sync.lock`
|tracking branch への publish の lease

|`.aidev/knowledge/.cache/`
|`plan.json`（hook がセッションに渡す batch の計画）と agent の完了報告

|`.aidev/workflows/*/runs/`
|workflow の実行記録（`run.json`、`log.txt`、`reports/`、`logs/`、`diffs/`、`notes/`、`pull-request.md`）。実行の worktree の中に書かれる。コマンドの出力を含むのでコミットしない（xref:workflows-run[workflow の実行]）
|===

一時的に現れるもの: `.aidev/policy.candidate.yaml`（承認すると消えます）、`.aidev/ejected.json`（`aidev uninstall --package` が書き、`aidev init` が消します）。

=== 端末側（AIDEV_HOME）

`registry.json`（登録済み PKG の一覧）、`cache/update-check.json`（ADK 更新の確認結果）と、workflow の実行の worktree（`worktrees/<PKG 名>-<PKG のクローンの場所のハッシュ>/<ブランチ>`。xref:workflows-worktree[実行の worktree とブランチ]）を置きます。ADK 本体は `AIDEV_HOME` ではなく、installer を実行した clone にあります。`aidev uninstall` は `registry.json` と `cache/` を消します。`worktrees/` は、まだ push していない成果が残っていることがあるので消しません（`git worktree remove` で消します）。{project-name} 本体の開発者の端末には `developer.json` も置かれます（利用者には関係ありません）。
