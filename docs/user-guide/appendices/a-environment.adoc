== 環境変数

値をファイルに書かず、シェルの profile、ユーザー環境変数、pipeline の secret variable から渡します。

[%autowidth.stretch,options="header"]
|===
|変数 |説明

|`AZURE_DEVOPS_PAT`
|Azure DevOps の PAT。`aidev sync`（PR 作成）と MCP サーバーが使います。名前は `aidev.yaml` の `hosting.auth_env` で変えられます。

|`AIDEV_HOME`
|端末ごとの作業領域。既定は Windows `{aidev-home-win}`、POSIX `{aidev-home-posix}`。登録済み PKG の一覧と kit 更新確認のキャッシュを置きます。

|`AIDEV_NO_UPDATE_CHECK`
|設定すると新しい kit の確認をしません。CI では `1` にします。

|`AIDEV_CLAUDE_BIN`
|Claude Code の実行ファイルを直接指定します。通常は未設定です。

|`AIDEV_COPILOT_BIN` / `AIDEV_CODEX_BIN` +
`AIDEV_KIRO_BIN`
|同じく GitHub Copilot CLI（`copilot`）、OpenAI Codex CLI（`codex`）、Kiro CLI（`kiro-cli`）の実行ファイルを直接指定します。

|`AIDEV_AGENT`
|`aidev` が agent を起動するときに、その子プロセスにだけ設定する agent 名。hook はこれで policy の `agents.<name>` を適用します。自分で設定しないでください。

|`AIDEV_DEBUG`
|設定すると内部エラーの stack trace を表示します。

|`AIDEV_BIN_DIR`
|installer が起動スクリプトを置く場所を上書きします。`aidev uninstall` も同じ場所を見ます。

|`HTTPS_PROXY` / `https_proxy`
|HTTPS proxy の URL。remote の確認、`npx`、Claude Code が使います。

|`ANTHROPIC_MODEL`
|Claude Code 自身のモデル設定。`aidev` が起動する agent は `tools.agent_model` を優先します。

|`NO_COLOR`
|設定すると色付けを止めます。

|`AIDEV_KIT_URL` / `AIDEV_KIT_REF` +
`AIDEV_BOT_NAME` / `AIDEV_BOT_EMAIL`
|`pipelines/*.yml` が使う pipeline 変数。中央 kit の URL とブランチ、夜間 sync の bot の名前とメール。
|===

=== 設定例

.PowerShell（このセッションのみ）
[source,powershell]
----
$env:AZURE_DEVOPS_PAT = "<your-pat>"
----

.PowerShell（ユーザー環境変数として保存）
[source,powershell]
----
[Environment]::SetEnvironmentVariable('AZURE_DEVOPS_PAT', '<your-pat>', 'User')
----

.bash
[source,bash]
----
export AZURE_DEVOPS_PAT="<your-pat>"
----

=== 安全な扱い

* token は secret manager や pipeline の secret variable から注入し、shell history に残るコマンドを避けます。
* `env` の出力を issue や PR に貼りません。
* token には必要最小の scope（PR 作成、Work Item 読み取り）と有効期限を設定します。
