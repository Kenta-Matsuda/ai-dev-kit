= ai-dev-kit User Guide sources

このディレクトリはユーザーガイドの AsciiDoc ソースです。日本語版（`index.adoc`）と英語版（`index-en.adoc` と `en/`）を、同じ構成・同じ ID で保ちます。kit の設計や実装状況は `docs/developer-guide/` にあり、このガイドには含めません。

== Quick start

[source,bash]
----
npm ci
npm run docs:check
----

生成物:

[source,text]
----
build/docs/ai-dev-kit-user-guide.html      # 日本語
build/docs/ai-dev-kit-user-guide.en.html   # 英語
----

== Layout

[source,text]
----
docs/user-guide/
├─ index.adoc                  日本語版のルート（include 順）
├─ _attributes.adoc            共通 attribute
├─ chapters/01-… 10-…          ユーザーガイド
├─ chapters/cli/               コマンドリファレンス（index.adoc + 1 コマンド 1 ファイル）
├─ appendices/                 付録
├─ index-en.adoc               英語版のルート（include 順）
├─ en/                         英語版の章と付録（_attributes.adoc, chapters/, appendices/）
└─ assets/user-guide.css       共通 stylesheet
----

`scripts/build-docs.js` が両言語を build し検証します。必須の章 ID は同スクリプトの `REQUIRED_IDS` にあります。

== Writing rules

* 読者がその場で必要なことだけを、短い文で書く。説明の長さより「次に何をするか」が分かることを優先する。
* 章とコマンドページに一意の ID を付け、内部リンクは `xref:ID[label]` で書く。両言語で同じ ID を使う。
* コマンドページのオプションは `AIDEV_NO_UPDATE_CHECK=1 node cli/bin/aidev.js <command> --help` と一致させる。既定値は `cli/commands/*.js` と `cli/lib/config.js` が正本。
* 実装されていない機能は書かない。
* 一方の言語を変えたら、もう一方も同じ内容に更新する。
* 「項目 | 説明」の 2 列表は `[%autowidth.stretch,options="header"]` で書く。1 列目は内容幅で折り返さず、残りが説明に回る。1 列目に複数の項目を並べるときは ` +` で改行する。
