[[cli-update]]
== aidev update

Updates the kit itself: the `aidev` CLI and the templates it carries. Package files are not touched.

=== Synopsis

[source,text]
----
aidev update [--dry-run] [--json]
----

=== Description

Fast-forwards the kit clone to `origin/main`. It stops if the clone has uncommitted changes, is not on `main`, or has diverged.

Nothing is written into any package. Taking the new templates into a package is xref:cli-apply[`aidev apply`], which each package team runs when it suits them; it is kept apart from the CLI update so that merging edited files and resolving conflicts can be done with time in hand. After updating, the packages registered on this machine that still carry templates from an older kit are listed.

It does not regenerate the Wiki, does not change `aidev.yaml` or the policy, and does not commit.

=== Options

[%autowidth.stretch,options="header"]
|===
|Option |Description

|`--dry-run`
|Show whether a newer kit exists; change nothing

|`--json`
|Machine-readable output
|===

=== Exit codes

[%autowidth.stretch,options="header"]
|===
|Code |Condition

|0
|Updated, or already up to date

|1
|The kit clone has uncommitted changes, is not on `main`, has diverged, or the fetch failed
|===

=== Examples

[source,bash]
----
aidev update
----

[source,text]
----
✓ updated ai-dev-kit 0.3.0 → 0.4.0 (499f940 → 7c1d2e3)
ℹ 2 package(s) on this machine still carry templates from an older kit:
    C:\work\demo-pkg (applied 499f940)
    C:\work\other-pkg (applied 9491efe)
    Run "aidev apply" in each when convenient; it merges the new templates with your edits.
----
