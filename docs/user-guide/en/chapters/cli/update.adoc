[[cli-update]]
== aidev update

Updates the kit and re-applies the distributed files to the package.

=== Synopsis

[source,text]
----
aidev update [options]
----

=== Description

. Fast-forwards the kit clone to `origin/main`. It stops if the clone has uncommitted changes, is not on `main`, or has diverged.
. Unless `--kit-only` is given, re-applies the distributed files to the current package (every registered package with `--all`). Files edited by hand are left as **conflicts** rather than replaced (`--force` replaces them).

The result is an ordinary diff in the package. Review it with `git diff`, commit, and open a pull request; after the merge the team only needs `git pull`.

It does not regenerate the Wiki, does not change `aidev.yaml` or the policy, and does not commit.

=== Options

[cols="2,3",options="header"]
|===
|Option |Description

|`--dry-run`
|Show what would change; write nothing

|`--json`
|Machine-readable output

|`--kit-only`
|Update the kit only; leave package files alone

|`--all`
|Re-apply to every package registered on this machine

|`--force`
|Replace distributed files that were edited by hand
|===

=== Exit codes

[cols="1,4",options="header"]
|===
|Code |Condition

|0
|Updated, or already up to date

|1
|The kit clone has uncommitted changes, is not on `main`, has diverged, or the fetch failed

|2
|A conflict with a hand-edited file remains
|===

=== Examples

[source,bash]
----
aidev update
----

[source,text]
----
✓ updated ai-dev-kit 0.2.0 → 0.2.1 (9491efe → e0aa66c)
✓ demo-pkg: updated 3 file(s)
    ~ .claude/agents/knowledge-builder.md
    ~ .claude/skills/knowledge-usage/SKILL.md
    ~ CLAUDE.md
    Review with "git diff", then commit so your team receives the update.
----

With a conflict (exit code 2):

[source,text]
----
✗ C:\work\demo-pkg: 1 file(s) were edited locally and were not replaced:
    .claude/settings.json — has been edited locally
    Re-run with --force to take the kit version, or send the change to ai-dev-kit as a PR.
----
