[[cli-sync]]
== aidev sync

Follows `main` (the tracking branch), updates the Wiki and opens a PR.

=== Synopsis

[source,text]
----
aidev sync [options]
----

=== Description

Fetches `origin/main`, updates the Wiki to match its tip, and turns the result into a PR.

. If the latest Wiki is already committed on the tracking branch, it does nothing (`git pull` brings it to you).
. It takes a work lock (sync lease) and checks the target out into a temporary worktree at `.aidev/cache/sync-worktree/`. **Your own checkout is not changed.**
. Inside the worktree it rewrites the inventory and manifest, and the knowledge-builder agent writes the prose for what changed (`--no-agent` leaves the prose for later).
. It commits on the `aidev/wiki-<sha>` branch, pushes, and opens a PR (on Azure DevOps with a token).
. It removes the worktree and releases the lock.

If it fails halfway, the lock and worktree stay behind. `--resume` continues, `--abort` discards them.

It does not merge the PR. With `generic` hosting it pushes and you open the PR by hand.

=== Options

[%autowidth.stretch,options="header"]
|===
|Option |Description

|`--to <sha>`
|Sync to this commit instead of the tip (must be reachable from the tracking branch)

|`--dry-run`
|Fetch and show what would change; write nothing

|`--no-pr`
|Commit on the local `aidev/wiki-<sha>` branch but do not push or open a PR

|`--resume`
|Continue a sync that stopped halfway

|`--abort`
|Discard a stopped sync (remove its worktree and release the lock)

|`--check-only`
|Only report whether the tracking branch moved

|`--json`
|Machine-readable output

|`--force`
|Take over a stale lock, or overwrite hand-edited Wiki pages

|`--no-agent`
|Update only the inventory and manifest; leave the prose for a later run

|`--agent-name <name>` +
`--agent-tool <tool>` +
`--agent-timeout <ms>` +
`--agent-model <model>` +
`--agent-batch-size <n>` +
`--survey`, `--no-survey`
|Same as xref:cli-knowledge[aidev knowledge]
|===

=== Exit codes

[%autowidth.stretch,options="header"]
|===
|Code |Condition

|0
|Finished. Nothing needed doing. The PR could not be opened and manual instructions were shown

|1
|Fetch failed, a lock already exists, `--to` is not reachable, hand edits without `--force`, the agent failed or stopped halfway

|4
|`--check-only` found the Wiki broken. Verification inside the worktree failed
|===

=== Examples

Normal catch-up:

[source,bash]
----
aidev sync
----

[source,text]
----
aidev sync
  tracking branch  origin/main
  target           9f8e7d6
  wiki describes   1a2b3c4
  sync branch      aidev/wiki-9f8e7d6c5b4a

ℹ generation target changes: +2 ~5 -0 →1 (=155)
✓ acquired sync lease (ttl 120m)
✓ created worktree at .aidev/cache/sync-worktree (9f8e7d6)
✓ inventory rewritten (162 targets, 1 shard(s))
ℹ running the knowledge-builder agent: 7 generation target(s) in 1 batch(es) of up to 20
✓ knowledge-builder completed 7/7 queued generation target(s) ($0.6210)
✓ pushed aidev/wiki-9f8e7d6c5b4a
✓ opened pull request !123 https://dev.azure.com/contoso/Platform/_git/demo-pkg/pullrequest/123
    Merging is always a human decision. After the merge, "git pull" brings the Wiki to every clone.
✓ sync lease released
----

Only see what would change:

[source,bash]
----
aidev sync --dry-run
----

Continue or discard a stopped sync:

[source,bash]
----
aidev sync --resume
aidev sync --abort
----
