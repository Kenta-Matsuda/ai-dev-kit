[[cli-task]]
== aidev task

Tracks the progress of issue-to-pr tasks.

=== Synopsis

[source,text]
----
aidev task list [--all] [--json]
aidev task show <taskId> [--json]
aidev task resume <taskId> [--dry-run] [--json]
aidev task advance [<taskId>] [--state <STATE>] [--reason <text>] [--dry-run] [--json]
aidev task abandon <taskId> [--reason <text>] [--dry-run] [--json]
----

=== Description

Keeps the state of tasks driven by the `issue-to-pr` agent in a local cache, `.aidev/tasks/<taskId>.json`. The source of truth is the pull request and Work Item in Azure DevOps; `advance` and `resume` look at the pull request and move the state forward. It never merges, and it never starts a task (the `issue-to-pr` agent does that).

[source,text]
----
IMPLEMENTING → PKG_PR_OPEN → PKG_PR_MERGED → SYNCHRONIZING → WIKI_PR_OPEN → DONE
                   │              │              └── SYNC_FAILED ──(resume)──┘
                   └── PKG_PR_ABANDONED          WIKI_PR_ABANDONED / BLOCKED
----

=== Subcommands

[%autowidth.stretch,options="header"]
|===
|Subcommand |What it does

|`list`
|Lists unfinished tasks. `--all` includes finished ones.

|`show <taskId>`
|Shows the state, Work Item, branch, pull request and the states that can come next.

|`resume <taskId>`
|Advances as far as it can and tells you what a human or an agent does next.

|`advance [<taskId>]`
|Looks at the pull request and moves one step forward. Without an id it processes every unfinished task in turn.

|`abandon <taskId>`
|Abandons the task and releases its work lease. Does not close the pull request.
|===

=== Options

[%autowidth.stretch,options="header"]
|===
|Option |Description

|`--json`
|Machine-readable output

|`--all`
|`list`: include finished tasks

|`--dry-run`
|Show the transition; write nothing

|`--state <STATE>`
|`advance <taskId>`: move to this state without looking at the pull request (only transitions the diagram allows)

|`--reason <text>`
|`advance --state` / `abandon`: a note kept in the record
|===

=== Exit codes

[%autowidth.stretch,options="header"]
|===
|Code |Condition

|0
|Success (also when nothing moved)

|1
|No task record, a transition that is not allowed, a pull request API failure, or one or more failures in `advance` without an id
|===

=== Examples

[source,bash]
----
aidev task list
aidev task advance wi-4711
aidev task resume wi-4711
aidev task abandon wi-4711 --reason "requirements changed"
----

Advance every task from the nightly pipeline:

[source,bash]
----
aidev task advance
----
