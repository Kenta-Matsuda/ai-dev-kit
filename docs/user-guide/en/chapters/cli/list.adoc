[[cli-list]]
== aidev list

Lists workflows (with their approval state), agents, skills, and the PKGs on this machine.

=== Synopsis

[source,text]
----
aidev list workflows [--json]
aidev list agents [--json]
aidev list skills [--json]
aidev list packages [--json]
----

=== Description

[%autowidth.stretch,options="header"]
|===
|object |What it shows

|`workflows`
|The state of each workflow under `.aidev/workflows/` (`approved` / `not on origin/main` / `changed since origin/main` / `invalid: …`) and its description. The ADK bundles no workflows, so only this PKG's workflows are listed

|`agents`
|The PKG's `.aidev/agents/` and the agents bundled with the ADK. Name, origin (`this PKG` / `ADK`), description. `⚠` is added when `name` in the frontmatter differs from the file name

|`skills`
|The PKG's `.aidev/skills/` and the skills bundled with the ADK. Name, origin, description

|`packages`
|The PKGs set up with `aidev init` on this machine. Name, path, template state (`templates current` / `templates from <commit>` (still on an older ADK; the command that takes the new templates is shown) / `missing` (no `aidev.yaml` at that path)). The PKG you are in is marked `*`. Works outside a PKG too
|===

For `workflows` / `agents` / `skills`, with the same name the PKG's one takes precedence over the bundled one.

Any name listed by `packages` can be passed to any command as `--package <name>` (see xref:cli-common-options[Common options]).

=== Options

[%autowidth.stretch,options="header"]
|===
|Option |Description

|`--json`
|Machine-readable output. Each row of `workflows` has `name`, `description`, `status`, `steps` (the number of steps) and `writable` (the `writable` of all steps together). Each row of `packages` has `name`, `path`, `present` (whether `aidev.yaml` is there), `here` (whether it is the PKG you are in), `templates` (`current` / `behind` / `unknown`) and `applied` (the ADK commit it took)
|===

=== Exit codes

[%autowidth.stretch,options="header"]
|===
|Code |Condition

|0
|Displayed

|1
|No object, or an object other than `workflows` / `agents` / `skills` / `packages`
|===

=== Examples

[source,bash]
----
aidev list workflows
----

[source,text]
----
aidev list workflows
  write-tests           approved                          指定した対象のテストを既存の書き方で書き、通してから PR を作る
  e2e-tests             not on origin/main                主要画面の IT テストを Playwright で書く
  write-conventions     changed since origin/main         Wiki と根拠ソースから開発規約を書き、PR を作る

----

Check the PKGs on this machine and bring one on an older ADK forward:

[source,bash]
----
aidev list packages
aidev sync tools --package other-pkg
----

[source,text]
----
aidev list packages
  * demo-pkg   C:\work\demo-pkg   templates current
    other-pkg  C:\work\other-pkg  templates from 499f940: aidev sync tools --package other-pkg
    old-pkg    C:\work\old-pkg    missing (no aidev.yaml there)
    * = the package you are in.
    Run a command on another package with --package <name|path>.
----
