[[cli-mcp]]
== aidev mcp

Internal command started from `.mcp.json`.

=== Synopsis

[source,text]
----
aidev mcp azure-devops [--dry-run | --json]
----

=== Description

The distributed `.mcp.json` registers `aidev mcp azure-devops` as the command that starts the MCP server. It reads `hosting.organization` / `project` from `aidev.yaml` and the PAT from the environment variable named by `hosting.auth_env`, then starts the Azure DevOps MCP server (`@azure-devops/mcp@2.10.0`) with `npx`. The PAT is passed to the child process as an environment variable and never appears on a command line or in a log.

In a package whose `hosting.type` is not `azure-devops` it fails to start (nothing else is affected).

`--dry-run` / `--json` do not start the server; they show the resolved settings (without the token value).

=== Exit codes

[%autowidth.stretch,options="header"]
|===
|Code |Condition

|0
|Settings shown. The server exited with 0

|1
|No `aidev.yaml`, the token variable is not set, or `npx` could not start
|===

=== Example

[source,bash]
----
aidev mcp azure-devops --dry-run
----

[source,text]
----
aidev mcp azure-devops (dry run)
  package              @azure-devops/mcp@2.10.0
  organization         contoso
  project              Platform
  auth env             AZURE_DEVOPS_PAT (set; value not read)
----
