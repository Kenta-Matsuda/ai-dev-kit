[[cli-doctor]]
== aidev doctor

Checks the environment on this machine and in the package.

=== Synopsis

[source,text]
----
aidev doctor [--json]
----

=== Description

For the machine, it reports Node.js, git, where `aidev` and the kit live, whether a newer kit exists, how many packages are registered, and whether each AI tool is present and which version. Inside a package it checks every tool in `tools.default` of `aidev.yaml`; outside one, only `claude`. Inside a package it also reports `aidev.yaml`, `origin`, the policy, the tool and model agents run with, whether the token variable is set (the value is never read), the proxy, whether the remote is reachable, and the Wiki state.

Each line is `✓` (ok), `⚠` (warning) or `✗` (failure).

=== Exit codes

[%autowidth.stretch,options="header"]
|===
|Code |Condition

|0
|No `✗`

|1
|One or more `✗`
|===

=== Example

[source,bash]
----
aidev doctor
----

----
aidev doctor

  ✓ git                    git version 2.44.0.windows.1

  ✓ kit checkout           9491efe

  ✓ AIDEV_HOME             C:\Users\you\AppData\Local\ai-dev-kit
  ✓ registered packages    1
  ✓ claude                 2.1.278 (PATH (C:\Users\you\.local\bin\claude.exe))
  ✓ aidev.yaml             C:\work\demo-pkg

  ✓ remote origin          https://dev.azure.com/contoso/Platform/_git/demo-pkg

----
