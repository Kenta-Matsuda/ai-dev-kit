[[cli-doctor]]
== aidev doctor

Diagnoses the environment on this machine. With `<package>` (the name of a PKG registered on this machine, or a path) it also lists that PKG's state. The exit codes for CI belong to xref:cli-check[`aidev check`], run inside the PKG.

=== Synopsis

[source,text]
----
aidev doctor [<package>] [--json]
----

=== Description

It reports Node.js, the platform, git, the version of `aidev` and where the kit lives, the kit checkout and whether a newer kit exists, `AIDEV_HOME`, the registered PKGs (count and list), whether each supported AI tool (`claude`, `copilot`, `codex`, `kiro`) is present and which version, and the proxy. The result is the same in whatever directory you run it.

Each line is `✓` (ok), `⚠` (warn) or `✗` (fail). An AI tool that is not found is `⚠`. With `<package>`, the rows `package`, `aidev.yaml` (schema), `git repository` (branch), `remote origin`, `policy`, `agent tool` (`tools.agent` and model), `env <auth_env>` for Azure DevOps, `remote reachability`, `Wiki state` and `workflows` (count, approved, invalid) follow.

=== Options

[%autowidth.stretch,options="header"]
|===
|Option |Description

|`--json`
|Machine-readable output
|===

=== Exit codes

[%autowidth.stretch,options="header"]
|===
|Code |Condition

|0
|No `✗`

|1
|One or more `✗` (Node.js too old, git missing, the `<package>`'s `aidev.yaml` is broken, the Wiki is broken, a workflow is invalid). `<package>` not found
|===

=== Examples

[source,bash]
----
aidev doctor
----

[source,text,subs="attributes+"]
----
aidev doctor
  ✓ node                   v22.17.1
  ✓ platform               win32 x64
  ✓ git                    git version 2.44.0.windows.1
  ✓ aidev                  {aidev-version} @ C:\tools\ai-dev-kit
  ✓ kit checkout           9491efe
  ✓ kit update             up to date
  ✓ AIDEV_HOME             C:\Users\you\AppData\Local\ai-dev-kit
  ✓ registered packages    1
  ✓   package              demo-pkg — C:\work\demo-pkg
  ✓ claude                 Claude Code 2.1.278 (PATH (C:\Users\you\.local\bin\claude.exe))
  ⚠ copilot                GitHub Copilot CLI not found on PATH — needed to run agents (aidev sync wiki, aidev run workflow) (adapter not verified against the real tool by the kit maintainers)
  ⚠ codex                  OpenAI Codex CLI not found on PATH — …
  ⚠ kiro                   Kiro CLI not found on PATH — …
  ✓ proxy                  none configured

⚠ 3 warning(s); nothing blocking.
    For a package: aidev doctor <package name or path>. The CI gate is "aidev check" inside the clone.
----

With a package:

[source,bash]
----
aidev doctor demo-pkg
----
