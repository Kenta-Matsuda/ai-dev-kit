[[overview]]
== {project-name} とは

{project-name} は、チームの各リポジトリ（PKG）に **同じ Claude Code の設定** と **そのリポジトリ専用の LLM Wiki** を置き、`aidev` コマンドで保守するためのキットです。

導入すると、次の 3 つがそろいます。

* **同じ設定** — `.claude/`（agents・skills・hooks）、`CLAUDE.md`、`.mcp.json` をチーム全員で共有します。kit のテンプレートから置かれ、チームが編集できます。新しいテンプレートは `aidev apply` で取り込み、編集済みならマージします。`aidev check` は未解消の衝突と hooks の欠落だけを止めます。
* **LLM Wiki** — `.aidev/knowledge/` に、コードの構造と役割を説明する Markdown ページを生成します。Claude はソースを読む前にここを引きます。コードが進んだら `aidev sync` が追従し、PR を作ります。
* **書き込みの制限** — `.aidev/policy.yaml` に「AI が書いてよい場所」を定め、hook が毎回の書き込みを検査します。ソースは通常 read-only で、チームが agent ごとに許可を足せます。

=== 誰が何をするか

[%autowidth.stretch,options="header"]
|===
|役割 |すること

|全員（1 回）
|自分の端末に `aidev` を入れます。→ xref:install[端末に aidev を入れる]

|導入担当者（PKG につき 1 人、1 回）
|`aidev init` で設定を作り Wiki を生成し、PR でチームに配ります。→ xref:setup-owner[導入担当者の手順]

|メンバー
|`git pull` → `aidev init` → `claude`。質問はありません。→ xref:setup-member[メンバーの手順]
|===

=== しないこと

* PR をマージしません。マージは常に人間が行います。
* 実機で検証済みの AI ツールは Claude Code です。GitHub Copilot CLI・OpenAI Codex CLI・Kiro CLI は各ツールの非対話モードに沿ったアダプタで起動できますが、kit の保守者は実機で確認していません。hooks による書き込み policy の実行時強制は Claude Code だけです。
* 対応する hosting は Azure DevOps と `generic`（git のみ。PR は手動）だけです。
* サンドボックスではありません。hook と policy は「うっかり」を止める仕組みです。最終的な守りは token の権限と branch policy です。

=== 用語

[%autowidth.stretch,options="header"]
|===
|用語 |意味

|PKG
|{project-name} を導入する対象リポジトリの clone。`aidev` はその中で実行します。

|kit
|{project-name} 本体の clone。`aidev` コマンドの実体です。端末に 1 つです。

|LLM Wiki
|`.aidev/knowledge/` に生成される、AI 向けの説明ページ群。コードから作った派生情報で、正本ではありません。

|tracking branch
|Wiki が追いかけるブランチ。通常は `main` です。

|policy
|`.aidev/policy.yaml`。AI が書いてよいパス、書けないパス、常に禁止のパスを決めます。
|===
