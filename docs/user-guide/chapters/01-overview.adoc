[[overview]]
== {project-name} とは

{project-name} は、チームの AI コーディングツール（Claude Code など）を **全員が同じ設定・同じ権限・同じ前提知識** で使えるようにするキットです。`aidev` コマンドで導入し、保守します。

[[overview-change]]
=== 導入による変化

各自が好きなように AI を使う状態から、**チームで決めた枠の中で AI を使う** 状態になります。

[%autowidth.stretch,options="header"]
|===
|　 |導入前 |導入後

|AI ツールの設定
|人によって違う
|チームで共通。リポジトリに入っていて、全員が同じものを使う

|AI が前提にする知識
|毎回ゼロから読ませる
|コードの説明書がリポジトリにあり、AI が最初に読む

|AI が書き換えてよい範囲
|その場の判断
|チームで決めた範囲だけ。範囲外への書き込みは自動で止まる

|AI に任せる大きめの仕事
|その場で口頭指示する
|内容と範囲を事前に決めてレビューし、承認したものだけ実行できる
|===

変わらないことが 1 つあります。**成果物を取り込むかどうかを決めるのは人間です。** AI が作った変更は必ず人のレビューを通ります。{project-name} が勝手に取り込むことはありません。

[[overview-roles]]
=== 役割と責任

作業内容は役割によって大きく異なります。まず自分がどちらに該当するかを確認してください。

[%autowidth.stretch,options="header"]
|===
|役割 |人数 |責務

|**Engineering Manager**
|リポジトリに 1 人
|**決める人**です。AI に何をさせてよいかを決め、チーム共通の設定と AI 向けのコード説明書を用意して配ります。AI に任せる仕事を定義します。上がってきた変更をレビューして取り込みます。

|**Developer**
|そのほか全員
|**使う人**です。配られた設定を自分の環境に取り込み、AI と一緒に日々の開発をします。定義済みの仕事を AI に実行させ、できた成果物をレビューに出します。**決めることは何もありません。**
|===


[[overview-flow]]
=== 全体フロー

.Engineering Manager と Developer が、それぞれ何をするか
[mermaid]
----
sequenceDiagram
  participant L as Engineering Manager
  participant M as Developer

  rect rgb(232, 243, 250)
    Note over L,M: ① 準備（最初に 1 回）
    L->>L: チーム共通の設定を用意する
    L->>L: AI 向けのコード説明書を用意する
    L->>M: レビューを経てチームに配る
    M->>M: 受け取って自分の環境を整える
  end

  rect rgb(233, 247, 240)
    Note over L,M: ② 日々の開発
    M->>M: AI と一緒に開発してコミットする
    M->>L: 変更をレビューへ提出
    L->>L: 中身を確認して取り込む
  end

  rect rgb(242, 237, 255)
    Note over L,M: ③ AI に仕事を任せる
    L->>L: 任せる仕事の内容と範囲を決める
    L->>L: レビューを経て「承認済み」にする
    M->>M: 承認済みの仕事を AI に実行させる
    M->>L: 成果物をレビューへ提出
    L->>L: 中身を確認して取り込む
  end
----

③ は ② と並行して進みます。順番に終わらせる必要はありません。

[[overview-terms]]
=== 用語

本ガイドで繰り返し使用する用語です。その他の用語は初出の章で説明します。

[%autowidth.stretch,options="header"]
|===
|用語 |意味

|PKG
|{project-name} を導入する対象のリポジトリ。あなたが日々開発しているリポジトリのことです。

|kit
|{project-name} 本体。`aidev` コマンドの実体で、各自の端末に 1 つ置きます。

|LLM Wiki
|AI 向けのコード説明書。PKG のコードから自動で作られ、リポジトリでチームと共有します。

|workflow
|AI に任せる仕事の定義。何をさせるか、どこまで書き換えてよいか、いくらまで使ってよいかを書いたものです。
|===
