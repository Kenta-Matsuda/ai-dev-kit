[[knowledge]]
== LLM Wiki

LLM Wiki は、PKG のコードの構造と各ファイルの役割を AI 向けに説明する Markdown ページ群です。`.aidev/knowledge/` にコミットし、チームで共有します。

* 生成するのは `aidev knowledge build` と `aidev sync` です。どちらも knowledge-builder agent（Claude Code）を起動して本文を書きます。
* Wiki は正本ではありません。各記述は根拠ファイルへのリンクを持ち、Claude はリンク先で確認します。
* Wiki が無い間、AI の書き込みはすべて止まります。

[[knowledge-files]]
=== 何が生成されるか

[cols="2,3",options="header"]
|===
|パス |内容

|`.aidev/knowledge/index.md`
|入口。Claude が最初に読みます。

|`.aidev/knowledge/overview.md`
|リポジトリの地図（目的・構成・ビルド/テスト方法・主要モジュール）。

|`.aidev/knowledge/**/*.md`
|生成対象ごとの説明ページ。

|`.aidev/knowledge/manifest.json`, `inventory/*.json`
|Wiki が説明しているコミットと、ファイルごとのハッシュ。**CLI が管理します。触りません。**

|`.aidev/knowledge/.cache/`
|agent との受け渡しファイル。gitignore 済みです。
|===

[[knowledge-scope-vs-evidence]]
=== 生成対象と調査範囲

* **生成対象** — ページを作るパス。`aidev.yaml` の `package.include` です。
* **調査範囲** — agent が裏付けに読んでよいファイル。既定は PKG 全体から `secrets_paths` を除いたものです。

生成対象を `docs/**` だけにしても、agent はコードやテストを読んで確認します。調査範囲のファイルが変わると、次の build で全ページが再生成の対象になります。

[[knowledge-agent]]
=== 生成の進み方

`aidev knowledge build` は次の順で進みます。

. 生成対象を走査し、前回から変わったファイルと前回未完了のファイルを queue に入れます（既定は差分だけ。`--full` で全部）。
. manifest と inventory を書きます。この時点で構造は最新です。
. `overview.md` が無いか全部を作り直すときは、まず **survey** が `overview.md` と `index.md` を書きます。
. queue を 20 件ずつの **batch** に分け、batch ごとに Claude Code を 1 回起動します。1 回の時間予算は 30 分です。
. batch が終わるたびに進捗を保存します。

[source,text]
----
ℹ running the knowledge-builder agent: 163 generation target(s) in 9 batch(es) of up to 20, after a survey run
✓ survey complete in 3m 12s ($0.4120)
ℹ batch 1/9: 20 target(s), src/api/auth.ts … src/api/users.ts
    batch 1/9: 7/20 target(s) reported done, 1m 30s elapsed…
✓ batch 1/9 complete: 20/20 in 4m 2s ($0.5533)
ℹ batch 2/9: 20 target(s), src/core/a.ts … src/core/z.ts (about 32m 16s left)
----

`$` は Claude Code が報告したコストです。`(about … left)` は残り時間の見積もりです。

=== 止まったとき

再開は常に **同じコマンド** です。終わった分は保存されています。

[cols="2,3",options="header"]
|===
|表示 |すること

|`✗ … ran out of time`
|同じコマンドで再開します。繰り返すなら `--agent-batch-size 10` を付けるか、`aidev.yaml` の `knowledge.agent_timeout_ms` を増やします。

|`⚠ … partial Wiki progress: 120/163 completed, 43 remain.`
|同じコマンドで再開します。

|`✗ … made no Wiki progress: 0/20`
|1 件も終わりませんでした。続けて表示される `Claude result:` を読んで原因を直し、再開します。

|`⚠ the knowledge-builder agent did not run`
|Claude Code が見つかりません。`aidev doctor` の `claude` 行を直します。

|Ctrl-C
|同じコマンドで再開します。
|===

`aidev status` が `⚠️ N page(s) still await prose regeneration` の間は本文が未完成です。

[[knowledge-handedit]]
=== 手編集しない理由

ページごとにハッシュが記録され、手編集は `aidev status` / `aidev check` が検出します。

[source,text]
----
⚠ 2 Wiki page(s) edited by hand since generation:
    .aidev/knowledge/src/api/auth.md (modified)
----

手編集があると `aidev knowledge build` と `aidev sync` は止まり、上書きするかどうかを人間に委ねます（`--force` で上書き）。手編集は次の生成で失われます。内容が間違っているなら、ソース側（コメントや構造）を直してください。

[[knowledge-scope-flag]]
=== 一部だけ作り直す

[source,bash]
----
aidev knowledge build --scope src/api
----

`src/api` 配下のページだけを queue に入れます。範囲外の変更は次回に持ち越されます。
