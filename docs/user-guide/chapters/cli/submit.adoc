[[cli-submit]]
== aidev submit

workflow をブランチと PR にして提出します。PR のマージが承認です。

=== 書式

[source,text]
----
aidev submit workflow <name> [--no-push] [--dry-run] [--json]
----

=== 説明

定義を検証し、`aidev/workflow-<name>` ブランチに `workflow.yaml` と、それが参照する PKG 内の agent（`.aidev/agents/`）・skill（`.aidev/skills/`）を `aidev: workflow <name>` としてコミットし、push して PR を作ります（Azure DevOps。`generic` hosting では push まで行い、PR は手で作ります）。PR 本文には目的、ステップごとの内容（順番・`description`・agent・書ける場所・その agent の skill・ツール・MCP server・起動できるサブエージェント、`for_each` の対象と同時実行数、同時に走る並列グループ、`until`）、agent と skill のファイル（新規か変更か）、上限と、「マージがこの workflow を承認する」旨が書かれます。定義が `inputs`・`provide`・`never_commit` を持つときは、**Inputs (--input name=value)**（名前、説明、必須か既定値、`pattern`、リポジトリ内のパスか、コマンドに届くか）、**Provided from the checkout**、**Never committed** の節も入ります（xref:workflows-inputs[実行ごとに変わる値を受け取る]、xref:workflows-provide[worktree に無いファイルを用意する]、xref:workflows-never-commit[決してコミットしないもの]）。

承認済みの workflow を直した提出では、さらに次が入ります。

* **What changed against the approved workflow**: `origin/main` の版から、追加・削除・並べ替えたステップと、変わったステップの項目（`prompt`、`writable`、`until` など）、`limits`・`inputs`・`provide`・`never_commit` などトップレベルの変更。
* **Estimate**: 費用の見積もり（楽観〜悲観）の、変更前と変更後。
* **Why this change**: `aidev modify` で直したとき（その `modify` が承認済みの版から始めたとき）、頼んだこと、`--from-run` の実行の止まった理由と記録された失敗の出力、agent が見つけた原因（`CAUSE:`）、agent の説明。`modify` の後に手で編集していれば、その旨。

本文の全文は `.aidev/cache/submit/<name>.md` にも書きます（`generic` hosting で PR を手で作るときに貼ります）。Azure DevOps の上限（4000 文字）を超えるときは、agent の説明から省き、それでも超えるなら途中を行の区切りで切ります。切った所には全文のファイルの場所を書き、**Files under review** と「マージがこの workflow を承認する」旨は残します。短くした本文を送ったときは、その旨を表示します。

既に `origin/main` と同じなら `already matches origin/main; nothing to submit.` と表示して何もしません。

=== オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--no-push`
|ローカルのブランチにコミットするだけで、push と PR はしない

|`--dry-run`
|ブランチ・宛先・対象ファイルを表示し、ブランチもコミットも push も PR も作らない

|`--json`
|JSON で出力する
|===

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|PR を作った（または既に承認済み）。`--dry-run`

|1
|`workflow` 以外の object、名前が無い。定義が不正、agent か skill が PKG にも ADK にも無い。参照するファイルが手元に無い。ブランチ作成・コミット・push の失敗
|===

=== 例

[source,bash]
----
git diff -- .aidev/workflows/write-tests/ .aidev/agents/ .aidev/skills/
aidev submit workflow write-tests
----

[source,text]
----
aidev submit workflow write-tests
✓ on branch aidev/workflow-write-tests
✓ committed 3f2a9c1b7d0e (1 file(s))
✓ pushed aidev/workflow-write-tests
✓ pull request !124 created (aidev/workflow-write-tests → main)
    Once it is merged, anyone with the branch fetched can run: aidev run workflow write-tests
----
