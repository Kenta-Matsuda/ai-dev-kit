[[cli-check]]
== aidev check

整合性を検査し、結果を終了コードで返します。CI 用です。

=== 書式

[source,text]
----
aidev check [options]
----

=== 説明

`aidev status` と同じ検査を行い、最初に見つかった問題の種類を終了コードにします。順序は drift（2）→ policy（3）→ Wiki（4）です。

`aidev.yaml` が無いディレクトリと eject 済みのリポジトリでは、何もせず 0 で終わります。警告（Wiki が HEAD より遅れている、本文が未生成、`main` が進んでいる）は 0 のままで、`--strict` を付けると 2 になります。

=== オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--strict`
|警告（Wiki が HEAD より遅れている、本文が未生成、tracking branch が先行）も失敗（終了コード 2）にする

|`--json`
|JSON で出力する

|`--no-remote`
|remote に接続しない
|===

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|整合している

|1
|`aidev.yaml` が壊れているなどの一般エラー

|2
|`.aidev/materialized.json` が無い、`aidev apply` の衝突マーカーが残っている、または `.claude/settings.json` から kit の hooks が消えている。チームがツール設定ファイルを編集しただけなら通ります。`--strict` 時の警告

|3
|`.aidev/policy.yaml` が無い、または読めない

|4
|Wiki が無い・壊れている（manifest が読めない、inventory が矛盾している）、または tracking branch への publish の lease が期限切れのまま残っている
|===

=== 例

[source,bash]
----
aidev check
----

[source,text]
----
aidev check
  head         9f8e7d6
  knowledge    9f8e7d6
  tracking     9f8e7d6
  tool config  ok (1 customised)
  policy       valid
✓ environment is consistent.
----

失敗の例（終了コード 2）:

[source,text]
----
✗ [exit 2] 1 tool configuration file(s) carry unresolved conflict markers. Resolve them and run "aidev apply" to record the result.
    conflict: .claude/settings.json
----
