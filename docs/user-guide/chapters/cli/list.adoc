[[cli-list]]
== aidev list

workflow（承認状態つき）、agent、skill、この端末の PKG の一覧を表示します。

=== 書式

[source,text]
----
aidev list workflows [--json]
aidev list agents [--json]
aidev list skills [--json]
aidev list packages [--json]
----

=== 説明

[%autowidth.stretch,options="header"]
|===
|object |表示

|`workflows`
|`.aidev/workflows/` の各 workflow の状態（`approved` / `not on origin/main` / `changed since origin/main` / `invalid: …`）と説明。ADK は workflow を同梱しないので、並ぶのはこの PKG の workflow だけ

|`agents`
|PKG の `.aidev/agents/` と ADK 同梱の agent。名前、由来（`this PKG` / `kit`）、説明。frontmatter の `name` がファイル名と違えば `⚠` を添える

|`skills`
|PKG の `.aidev/skills/` と ADK 同梱の skill。名前、由来、説明

|`packages`
|この端末で `aidev init` した PKG。名前、パス、テンプレートの状態（`templates current` / `templates from <commit>`（古い ADK のまま。取り込むコマンドを添える）/ `missing`（そのパスに `aidev.yaml` が無い））。今いる PKG に `*` が付く。PKG の外でも使える
|===

`workflows` / `agents` / `skills` では、同名なら PKG のものが ADK 同梱のものより優先されます。

`packages` に出る名前は、どのコマンドにも `--package <name>` で渡せます（xref:cli-common-options[共通オプション]）。

=== オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--json`
|JSON で出力する。`workflows` の各行は `name`・`description`・`status`・`steps`（ステップの数）・`writable`（全ステップの `writable` を合わせたもの）を持つ。`packages` の各行は `name`・`path`・`present`（`aidev.yaml` があるか）・`here`（今いる PKG か）・`templates`（`current` / `behind` / `unknown`）・`applied`（取り込んだ ADK のコミット）を持つ
|===

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|表示した

|1
|object が無い、または `workflows` / `agents` / `skills` / `packages` 以外
|===

=== 例

[source,bash]
----
aidev list workflows
----

[source,text]
----
aidev list workflows
  write-tests           approved                          指定した対象のテストを既存の書き方で書き、通してから PR を作る
  e2e-tests             not on origin/main                主要画面の IT テストを Playwright で書く
  write-conventions     changed since origin/main         Wiki と根拠ソースから開発規約を書き、PR を作る

----

この端末の PKG を確認して、古いテンプレートの PKG に取り込む:

[source,bash]
----
aidev list packages
aidev sync tools --package other-pkg
----

[source,text]
----
aidev list packages
  * demo-pkg   C:\work\demo-pkg   templates current
    other-pkg  C:\work\other-pkg  templates from 499f940: aidev sync tools --package other-pkg
    old-pkg    C:\work\old-pkg    missing (no aidev.yaml there)
    * = the package you are in.
    Run a command on another package with --package <name|path>.
----
