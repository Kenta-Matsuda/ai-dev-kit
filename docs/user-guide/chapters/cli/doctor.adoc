[[cli-doctor]]
== aidev doctor

端末と PKG の実行環境を診断します。

=== 書式

[source,text]
----
aidev doctor [--json]
----

=== 説明

端末について、Node.js、git、`aidev` と kit の場所、新しい kit の有無、登録済み PKG 数、AI ツールの有無とバージョンを報告します。PKG の中では `aidev.yaml` の `tools.default` にある各ツールを、PKG の外では `claude` だけを調べます。PKG の中で実行すると、さらに `aidev.yaml`、`origin`、policy、agent を動かすツールとモデル、token 環境変数の有無（値は読みません）、proxy、remote への到達性、Wiki の状態を報告します。

各行は `✓`（ok）、`⚠`（warn）、`✗`（fail）です。

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|`✗` が無い

|1
|`✗` が 1 つ以上ある
|===
