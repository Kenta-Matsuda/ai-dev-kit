[[cli-uninstall]]
== aidev uninstall

この端末から `aidev` を消します。`--package` を付けると、その PKG から ADK の管理を外します（旧 eject）。`--all` は登録済みの全 PKG から外してから端末の `aidev` を消します。

=== 書式

[source,text]
----
aidev uninstall --dry-run
aidev uninstall --yes [--json]
aidev uninstall --package <name|path> --yes [--keep-assets] [--force] [--json]
aidev uninstall --all --yes [--json]
----

=== 説明

==== 引数なし — 端末から消す

installer が置いたものを消します。①起動スクリプト（Windows: `aidev.cmd` と `aidev.ps1`、POSIX: `aidev`。installer が生成したものだけ）、②Windows ではユーザー PATH に足した起動スクリプトの場所、③`AIDEV_HOME` の `registry.json` と `cache/`。workflow の実行の worktree（`AIDEV_HOME/worktrees/`）は、まだ push していない成果が残っていることがあるので消しません（`git worktree remove` で消します）。

消さないものと、消したいときのコマンドを表示します。

* ADK の clone。`aidev` はこの中で動いているので、表示された `Remove-Item` / `rm -rf` を後で自分で実行します。
* 登録済みの各 PKG に ADK が置いたファイル。commit されてチームで共有しているので、消すならチームの変更として PR にします。先に `aidev uninstall --package <name> --yes` を実行するか（Wiki と `aidev.yaml` は残ります）、表示された `git rm` を PKG の clone で実行します（Wiki も消えます）。

対話の確認はしません。`--yes` が無ければ一覧を表示して終了コード 1 で止まります。消すものが無くても 0 で終わります。

再インストールは ADK の clone で installer を実行します（xref:install[aidev のインストール]）。

==== `--package` — PKG から ADK の管理を外す（旧 eject）

`--package` には xref:cli-list[`aidev list packages`] に出る名前か、PKG のパスを渡します（PKG の中なら `.`）。

順に、①`.claude/settings.json` から `aidev hook` の 5 つの hook（session-start、guard-write、quality-gate、after-bash、session-stop）を外し、②`.aidev/policy.yaml`、`.aidev/materialized.json`、`.aidev/cache/` などの管理ファイルを消し、③`--keep-assets` が無ければ ADK が置いたツール設定ファイル（`.claude/**`、`CLAUDE.md`、他のツールの分）を消し、④`.aidev/ejected.json` を書いて端末の登録から外します。

残すもの: PKG のファイル、`.aidev/knowledge/`（Wiki）、`aidev.yaml`、`.aidev/workflows/`。

eject 後、`aidev check` は 0 を返します。CI から `aidev check` を外してください。`aidev init` で再導入できます。

対話の確認はしません。`--yes` が無ければ一覧を表示して終了コード 1 で止まります。tracking branch への publish が進行中（有効な lease がある）だと `--force` 無しでは拒否します。

==== `--all` — 全 PKG から外し、端末からも消す

登録済みの各 PKG に `--package` と同じ処理を順に行い、最後に端末から `aidev` を消します。どの PKG かで止まるとそこで終わります。`--yes` が要ります。

=== オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--yes`
|確認済みとして実行する

|`--dry-run`
|消すものと、残すものを消すコマンドを表示し、何も書かない

|`--json`
|JSON で出力する

|`--all`
|登録済みの全 PKG から ADK を外し、端末からも消す

|`--force`
|`--package` と併用: eject 済みでも、publish が進行中でも、管理の痕跡が無くても実行する

|`--keep-assets`
|`--package` と併用: ADK が置いたツール設定ファイル（`.claude/**`、`CLAUDE.md` など）を残す
|===

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|消した。消すものが無かった。`--dry-run`

|1
|`--yes` が無い。`--package` の PKG が見つからない、管理の痕跡が無い、publish が進行中（`--force` 無し）。`--package` と `--all` を同時に指定した
|===

=== 例

[source,bash]
----
aidev uninstall --package demo-pkg --dry-run   # その PKG から ADK を外す前に確認
aidev uninstall --package demo-pkg --yes
git -C C:\work\demo-pkg add -A && git -C C:\work\demo-pkg commit -m "chore: eject from ai-dev-kit"

aidev uninstall --dry-run
aidev uninstall --yes
----

最後に表示される「ADK の clone を消すコマンド」は、clone した場所に合わせて実行します。

.Windows（PowerShell）
[source,powershell]
----
Remove-Item -Recurse -Force C:\tools\ai-dev-kit
----

.macOS / Linux / WSL
[source,bash]
----
rm -rf ~/ai-dev-kit
----
