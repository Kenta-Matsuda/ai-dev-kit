= コマンドリファレンス

[[cli-reference]]
== コマンドリファレンスの読み方

`aidev` の全コマンドを 1 コマンド 1 ページで説明します。各ページは **書式 → 説明 → オプション → 終了コード → 例** の順です。オプションは `aidev <command> --help` と同じです。

[[cli-syntax]]
=== 共通の書式

[source,text]
----
aidev <verb> [<object>] [<name>] [options]
----

コマンドは動詞で始まり、対象（`workflow`、`policy`、`kit`、`wiki` など）と名前が続きます。

* オプションは `--name` または `--name <value>` です。`--name=value` も使えます。
* 受け付けないオプションはエラーです（`unknown option: --bogus`、終了コード 1）。
* `run`、`create`、`submit`、`list`、`remove`、`update`、`configure`、`show`、`evolve`、`hook`、`mcp` は対象（object）が必須です。
* PKG 用のコマンドは PKG の clone の中で実行します（サブディレクトリでも可。`init` はルートのみ）。

[[cli-common-options]]
=== 共通オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--json`
|機械可読な JSON だけを出力します（対応コマンドのみ）。

|`--dry-run`
|何が変わるかを表示し、何も書きません（対応コマンドのみ）。

|`--help`, `-h`
|コマンド一覧、またはそのコマンドのオプションを表示します。

|`--version`, `-V`
|kit のバージョンを表示します。
|===

`hook`、`mcp`、`update`、`uninstall` 以外のコマンドは、1 日 1 回、新しい kit があるか確認し、あれば先に更新するか尋ねます。更新したら、そのコマンドを新しい CLI で実行し直します。`AIDEV_NO_UPDATE_CHECK=1` で無効にできます。

[[cli-exit-codes]]
=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |意味

|0
|成功

|1
|一般エラー（不正なオプション、設定不備、不正な workflow、ネットワーク失敗、agent の失敗など）

|2
|drift: ツール設定の記録（`.aidev/materialized.json`）が無い、`aidev sync tools` の衝突マーカーが未解消、または `.claude/settings.json` から kit の hooks が消えている

|3
|permission: policy が無い・壊れている、または承認を拒否した

|4
|wiki: Wiki が無い・壊れている、または tracking branch への publish が途中で止まっている
|===

[[cli-commands]]
=== コマンド一覧

.開発する（PKG の clone の中で）
[%autowidth.stretch,options="header"]
|===
|コマンド |要約

|xref:cli-run[`aidev run workflow <name>`]
|承認済みの workflow を実行する（開発はここから）

|xref:cli-create[`aidev create workflow\|agent\|skill <name>`, `aidev create policy`]
|workflow・agent・skill を作る（書くだけで、実行はしない）。`policy` は書き込み権限 policy の候補を作り `--approve` で置く

|xref:cli-submit[`aidev submit workflow <name>`]
|workflow をブランチと PR にして提出する（マージ = 承認）

|xref:cli-list[`aidev list workflows\|agents\|skills`]
|workflow（承認状態）・agent・skill の一覧

|xref:cli-remove[`aidev remove workflow\|agent\|skill <name>`]
|workflow・agent・skill を削除する（参照されている agent・skill は拒否）
|===

.保守する（PKG の clone の中で）
[%autowidth.stretch,options="header"]
|===
|コマンド |要約

|xref:cli-init[`aidev init`]
|この PKG に {project-name} を導入する（初回は対話、2 人目以降は質問なし）

|xref:cli-check[`aidev check`]
|この PKG の状態を 1 画面で表示し、整合性を終了コードで返す（CI 用）

|xref:cli-sync[`aidev sync tools\|wiki [<package>]`]
|`tools`: kit の最新テンプレートをこの PKG に取り込む（編集済みはマージ）。`wiki`: LLM Wiki を HEAD に追従させ、別コミットとして積む
|===

.この端末に対して使う
[%autowidth.stretch,options="header"]
|===
|コマンド |要約

|xref:cli-update[`aidev update`]
|kit 本体（CLI とテンプレート）を更新する。PKG への取り込みは `aidev sync tools`

|xref:cli-doctor[`aidev doctor [<package>]`]
|端末の実行環境（Node.js、git、kit、AI ツール）を診断する。`<package>` を渡すとその PKG の状態も

|xref:cli-uninstall[`aidev uninstall [<package>] [--all]`]
|この端末から `aidev` を消す。`<package>` はその PKG を kit の管理から外す（旧 eject）
|===


.ツールから呼ばれる
[%autowidth.stretch,options="header"]
|===
|コマンド |要約

|xref:cli-hook[`aidev hook <…>`]
|AI ツールの hook から呼ばれる内部コマンド（`aidev --help` には出ない）

|===
