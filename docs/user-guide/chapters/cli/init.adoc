[[cli-init]]
== aidev init

この PKG に {project-name} を導入します。初回は対話、2 人目以降は質問なしです。

=== 書式

[source,text]
----
aidev init [options]
----

=== 説明

PKG の clone のルートで実行します。`aidev.yaml` が無ければ 4 つの質問（tools、Wiki の生成対象、秘密パス、hosting）をして `aidev.yaml` を書きます。既にあれば何も聞きません。どちらの場合も次を行います。

* `.aidev/.gitignore` を書く
* kit のテンプレートから、選んだツールの設定ファイル（`claude` なら `.claude/**`、`CLAUDE.md`、`.mcp.json`）を置き、`.aidev/materialized.json` にハッシュを記録する。既に記録がある clone では置かず、状態を報告するだけ
* この clone を端末に登録する
* `.aidev/policy.yaml` が無ければ候補を表示し、`Place this policy now? (y/N)` と尋ねる
* Wiki が無ければ `Build the LLM Wiki now? (Y/n)` と尋ね、生成する。未完成の Wiki があれば続きから再開する

初めての導入では Wiki の生成が既定です。設定は既にあるのに Wiki が無い clone（チームの PR が未マージ）では、既定は「生成しない」です。`--wiki` / `--no-wiki` で質問を省けます。初回に既存の `.claude/` などがあってテンプレートと違う場合はマージせず、そのファイルを残して終了コード 2 で止まります。`--force` で kit 版に置き換えます。

質問は stdin が端末で、`--yes` も `--json` も無いときだけ行います。

=== オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--dry-run`
|書く内容を表示し、何も書かない

|`--yes`
|質問せず、推定値とフラグの値を使う

|`--force`
|手編集された配布ファイルを置き換える

|`--json`
|JSON で出力する

|`--name <value>`
|PKG 名（既定: リポジトリ名）

|`--include <value>`
|Wiki の生成対象（glob、カンマ区切り。既定: ツリーから推定）

|`--exclude <value>`
|生成対象から外す glob（カンマ区切り）

|`--secrets <value>`
|AI に読ませないパス（glob、カンマ区切り）

|`--hosting <value>`
|`azure-devops` または `generic`（既定: `origin` の URL から推定）

|`--org <value>` +
`--project <value>` +
`--repository <value>`
|Azure DevOps の組織・プロジェクト・リポジトリ名

|`--tracking-branch <value>`
|Wiki が追いかけるブランチ（既定: `main`）

|`--tools <value>`
|設定する AI ツール。カンマ区切りで `claude`、`copilot`、`codex`、`kiro`（既定 `claude`）

|`--agent-model <value>`
|Wiki を書く agent のモデル（既定: `sonnet`）

|`--approve`
|policy を尋ねずに置く

|`--wiki`
|Wiki を尋ねずに生成（または再開）する

|`--no-wiki`
|Wiki を今は生成しない
|===

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|成功

|1
|git リポジトリでない、コミットが無い、サブディレクトリで実行した、Azure DevOps の組織などが決まらない。Wiki の生成が途中で止まった（`aidev init` の再実行で続行）

|2
|初回に、既存の `.claude/**`、`CLAUDE.md`、`.mcp.json` などが kit のテンプレートと違う（`--force` で置き換え）
|===

=== 例

初回（対話）:

[source,bash]
----
aidev init
----

質問なしで、policy も置き、Wiki も生成する:

[source,bash]
----
aidev init --yes --include "src/**,docs/**" --approve
----

Wiki は後回しにする:

[source,bash]
----
aidev init --no-wiki
----

2 人目以降:

[source,bash]
----
aidev init
----
