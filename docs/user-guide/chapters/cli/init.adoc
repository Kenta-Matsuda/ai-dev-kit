[[cli-init]]
== aidev init

この PKG に {project-name} を導入します。初回は対話、2 人目以降は質問なしです。Wiki は生成しません（xref:cli-sync-wiki[`aidev sync wiki`]）。

=== 書式

[source,text]
----
aidev init [options]
----

=== 説明

PKG の clone のルートで実行します。`aidev.yaml` が無ければ 4 つの質問（tools、Wiki の生成対象、秘密パス、hosting）をして `aidev.yaml` を書きます。既にあれば何も聞きません。どちらの場合も次を行います。

* `.aidev/.gitignore` を書く
* kit のテンプレートから、選んだツールの設定ファイル（`claude` なら `.claude/**`、`CLAUDE.md`、`.mcp.json`）を置き、`.aidev/materialized.json` にハッシュを記録する。既に記録がある clone では置かず、状態を報告するだけ
* この clone を端末に登録する
* `.aidev/policy.yaml` が無ければ候補を表示し、`Place this policy now? (y/N)` と尋ねる
* Wiki の有無を報告する。初回なら `next steps` として残りの手順（`aidev create policy --approve`、`aidev sync wiki --no-commit`、`git add … && git commit`、PR）を表示する。2 人目以降なら `ready. Run "aidev check" any time …` と表示する

初回に既存の `.claude/` などがあってテンプレートと違う場合はマージせず、そのファイルを残して終了コード 2 で止まります。`--force` で kit 版に置き換えます。

質問は stdin が端末で、`--yes` も `--json` も無いときだけ行います。

=== オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--dry-run`
|書く内容を表示し、何も書かない

|`--yes`
|質問せず、推定値とフラグの値を使う

|`--force`
|手編集された配布ファイルを置き換える

|`--json`
|JSON で出力する

|`--name <value>`
|PKG 名（既定: リポジトリ名）

|`--include <value>`
|Wiki の生成対象（glob、カンマ区切り。既定: ツリーから推定）

|`--exclude <value>`
|生成対象から外す glob（カンマ区切り）

|`--secrets <value>`
|AI に読ませないパス（glob、カンマ区切り）

|`--hosting <value>`
|`azure-devops` または `generic`（既定: `origin` の URL から推定）

|`--org <value>` +
`--project <value>` +
`--repository <value>`
|Azure DevOps の組織・プロジェクト・リポジトリ名

|`--tracking-branch <value>`
|Wiki が追いかけるブランチ。workflow の承認の基準にもなる（既定: `main`）

|`--tools <value>`
|設定する AI ツール。カンマ区切りで `claude`、`copilot`、`codex`、`kiro`（既定 `claude`）

|`--agent-model <value>`
|`aidev` が起動する agent のモデル（既定: `sonnet`）

|`--approve`
|policy を尋ねずに置く
|===

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|成功

|1
|git リポジトリでない、コミットが無い、サブディレクトリで実行した、Azure DevOps の組織などが決まらない

|2
|初回に、既存の `.claude/**`、`CLAUDE.md`、`.mcp.json` などが kit のテンプレートと違う（`--force` で置き換え）
|===

=== 例

初回（対話）:

[source,bash]
----
aidev init
----

[source,text]
----
ℹ LLM Wiki is not generated yet. Run "aidev sync wiki --no-commit" to build it (it takes a while).

ℹ next steps (you are setting this package up for your team):
    1. aidev sync wiki --no-commit          # builds (or continues) the LLM Wiki
    2. git add aidev.yaml .aidev .claude CLAUDE.md .mcp.json && git commit
    3. open a pull request so everyone gets the same setup
----

質問なしで、policy も置く:

[source,bash]
----
aidev init --yes --include "src/**,docs/**" --approve
----

2 人目以降:

[source,bash]
----
aidev init
----

[source,text]
----
✓ aidev.yaml is present (set up by your team); nothing to ask.
✓ tool configuration is current (18 file(s) for claude)
✓ AZURE_DEVOPS_PAT is set (value not read)
✓ .aidev/policy.yaml is present
✓ LLM Wiki is present (.aidev/knowledge/)

ℹ ready. Run "aidev check" any time, then start your AI tool (e.g. "claude") in this directory.
----
