[[cli-init]]
== aidev init

この PKG に {project-name} を導入します。初回は対話、2 人目以降は質問なしです。

=== 書式

[source,text]
----
aidev init [options]
----

=== 説明

PKG の clone のルートで実行します。`aidev.yaml` が無ければ 4 つの質問（tools、Wiki の生成対象、秘密パス、hosting）をして `aidev.yaml` を書きます。既にあれば何も聞きません。どちらの場合も次を行います。

* `.aidev/.gitignore` を書く
* kit のテンプレートから `.claude/**`、`CLAUDE.md`、`.mcp.json` を置き、`.aidev/materialized.json` にハッシュを記録する
* この clone を端末に登録する
* `.aidev/policy.yaml` が無ければ候補を表示し、`Place this policy now? (y/N)` と尋ねる
* Wiki の有無を確認し、次にすることを表示する

Wiki は生成しません（`aidev knowledge build` が行います）。既存の `.claude/` は配布版とマージしません。差分があれば終了コード 2 で止まり、`--force` で置き換えます。

質問は stdin が端末で、`--yes` も `--json` も無いときだけ行います。

=== オプション

[cols="2,3",options="header"]
|===
|オプション |説明

|`--dry-run`
|書く内容を表示し、何も書かない

|`--yes`
|質問せず、推定値とフラグの値を使う

|`--force`
|手編集された配布ファイルを置き換える

|`--json`
|JSON で出力する

|`--name <value>`
|PKG 名（既定: リポジトリ名）

|`--include <value>`
|Wiki の生成対象（glob、カンマ区切り。既定: ツリーから推定）

|`--exclude <value>`
|生成対象から外す glob（カンマ区切り）

|`--secrets <value>`
|AI に読ませないパス（glob、カンマ区切り）

|`--hosting <value>`
|`azure-devops` または `generic`（既定: `origin` の URL から推定）

|`--org <value>`, `--project <value>`, `--repository <value>`
|Azure DevOps の組織・プロジェクト・リポジトリ名

|`--tracking-branch <value>`
|Wiki が追いかけるブランチ（既定: `main`）

|`--tools <value>`
|設定する AI ツール。カンマ区切りで `claude`、`copilot`、`codex`、`kiro`（既定 `claude`）

|`--agent-model <value>`
|Wiki を書く agent のモデル（既定: `sonnet`）

|`--approve`
|policy を尋ねずに置く
|===

=== 終了コード

[cols="1,4",options="header"]
|===
|コード |条件

|0
|成功

|1
|git リポジトリでない、コミットが無い、サブディレクトリで実行した、Azure DevOps の組織などが決まらない

|2
|既存の `.claude/**`、`CLAUDE.md`、`.mcp.json` が配布版と違う（`--force` で置き換え）
|===

=== 例

初回（対話）:

[source,bash]
----
aidev init
----

質問なしで、policy も同時に置く:

[source,bash]
----
aidev init --yes --include "src/**,docs/**" --approve
----

2 人目以降:

[source,bash]
----
aidev init
----
