[[cli-update]]
== aidev update

ADK 本体（`aidev` CLI とテンプレート）を更新します。それ以外は何もしません。

=== 書式

[source,text]
----
aidev update [--dry-run] [--json]
----

=== 説明

対象は取りません。`aidev sync wiki` と打つと `aidev update takes no object` で止まります。Wiki は xref:cli-sync-wiki[`aidev sync wiki`]、ツール設定は xref:cli-sync-tools[`aidev sync tools`] です。

ADK の clone（`aidev` CLI とテンプレート）を `origin/main` に fast-forward します。clone に未コミットの変更がある、`main` 以外にいる、diverge している場合は止まります。

PKG には何も書きません。新しいテンプレートを PKG に取り込むのは xref:cli-sync-tools[`aidev sync tools --package <name>`] で、 Engineering Manager が都合のよいときに実行して PR にします。更新後、この端末に登録された PKG のうち古い ADK のテンプレートのままのものを一覧します。Wiki は再生成しません。`aidev.yaml` と policy は変更しません。コミットもしません。

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--dry-run`
|新しい ADK があるかを表示し、何も変えない

|`--json`
|JSON で出力する
|===

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|更新した、または最新だった

|1
|ADK の clone に未コミット変更がある、`main` 以外、diverge、fetch 失敗
|===

[source,bash]
----
aidev update
----

[source,text]
----
✓ updated ai-dev-kit 0.3.0 → 0.4.0 (499f940 → 7c1d2e3)
ℹ 2 package(s) on this machine still carry templates from an older kit:
    demo-pkg (applied 499f940)
    other-pkg (applied 9491efe)
    Run "aidev sync tools --package <name>" for each when convenient; it merges the new templates with your edits.
----
