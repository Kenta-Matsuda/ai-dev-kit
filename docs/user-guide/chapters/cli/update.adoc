[[cli-update]]
== aidev update

kit 本体（`aidev` CLI とテンプレート）を更新します。PKG のファイルは変えません。

=== 書式

[source,text]
----
aidev update [--dry-run] [--json]
----

=== 説明

kit の clone を `origin/main` に fast-forward します。clone に未コミットの変更がある、`main` 以外にいる、diverge している場合は止まります。

PKG には何も書きません。新しいテンプレートを PKG に取り込むのは xref:cli-apply[`aidev apply`] で、各 PKG のチームが都合のよいときに実行します（編集済みファイルのマージや衝突の解消に時間をかけられるよう、CLI の更新とは分けています）。更新後、この端末に登録された PKG のうち古い kit のテンプレートのままのものを一覧します。

Wiki は再生成しません。`aidev.yaml` と policy は変更しません。コミットもしません。

=== オプション

[%autowidth.stretch,options="header"]
|===
|オプション |説明

|`--dry-run`
|新しい kit があるかを表示し、何も変えない

|`--json`
|JSON で出力する
|===

=== 終了コード

[%autowidth.stretch,options="header"]
|===
|コード |条件

|0
|更新した、または最新だった

|1
|kit の clone に未コミット変更がある、`main` 以外、diverge、fetch 失敗
|===

=== 例

[source,bash]
----
aidev update
----

[source,text]
----
✓ updated ai-dev-kit 0.3.0 → 0.4.0 (499f940 → 7c1d2e3)
ℹ 2 package(s) on this machine still carry templates from an older kit:
    C:\work\demo-pkg (applied 499f940)
    C:\work\other-pkg (applied 9491efe)
    Run "aidev apply" in each when convenient; it merges the new templates with your edits.
----
