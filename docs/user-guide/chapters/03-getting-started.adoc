[[getting-started]]
== 利用開始

この章では、CLI専用checkoutのinstallから、wrapperの初回commitまでを順番に説明します。以下では中央kitを`ai-dev-kit`、対象PKGを`my-pkg`、wrapperを`my-pkg-ai-dev`とします。

[[getting-started-prerequisites]]
=== 前提条件

==== 必須ツール

* Node.js {node-min-version}以上
* Git
* Windows PowerShell、またはmacOS/Linux/WSLのbash
* 中央kit、対象PKG、作成するwrapper repositoryへのGitアクセス

Pythonは不要です。custom workflowもNode.jsで実行されます。

Claude Codeは、`--agent`を使うWiki prose生成と対話作業に必要です。installerとstructured-onlyのCLI処理はClaude Codeを検査せずに動作します。`aidev doctor`もClaude Codeの存在までは確認しません。

==== Azure DevOps連携に必要なもの

* Azure DevOps PATを環境変数として注入できること
* Git fetch/push用の認証
* Azure DevOps MCPを使う場合は`npx`とnpm registryへの接続

既定のPAT環境変数名は`{default-pat-env}`です。PAT値を`aidev.yaml`、`.mcp.json`、CLI引数、Git管理ファイルへ書かないでください。

==== repositoryの準備

Azure DevOps上で、空の`my-pkg-ai-dev` repositoryを作成します。中央kit、対象PKG、wrapperのURLを確認し、wrapper PR用botを使う場合は最小権限の専用identityを準備します。

[[getting-started-install-cli]]
=== 1. CLI専用checkoutをinstallする

一度だけ、移動・削除しない安定した場所へ中央kitをcloneします。このcheckoutの`origin`は中央{project-name}のまま、branchは`main`にします。

.Windows / PowerShell
[source,powershell]
----
git clone https://dev.azure.com/<org>/<project>/_git/ai-dev-kit "$env:LOCALAPPDATA\ai-dev-kit\source"
Set-Location "$env:LOCALAPPDATA\ai-dev-kit\source"
.\scripts\install.ps1
aidev --version
----

installerは既定で`$env:LOCALAPPDATA\ai-dev-kit\bin`へ`.cmd`と`.ps1` launcherを作り、user PATHを更新します。現在のterminalで見つからない場合は、新しいterminalを開きます。

.macOS / Linux / WSL
[source,bash]
----
git clone https://dev.azure.com/<org>/<project>/_git/ai-dev-kit "$HOME/.local/share/ai-dev-kit"
cd "$HOME/.local/share/ai-dev-kit"
./scripts/install.sh
export PATH="$HOME/.local/bin:$PATH"  # installerから案内された場合
aidev --version
----

POSIX版の既定launcherは`${AIDEV_BIN_DIR:-$HOME/.local/bin}/aidev`です。installerは必要に応じてshell profileへのPATH追記を案内しますが、自動変更はしません。

[NOTE]
====
launcherはCLI専用checkoutの絶対pathを保持します。checkoutを移動または削除した場合は、新しい場所からinstallerを再実行してください。
====

installerは、wrapper markerや`upstream` remoteを持つcheckoutからの通常installを拒否します。wrapper内の`scripts/install.*`は実行しません。

[[getting-started-create-wrapper]]
=== 2. wrapper repositoryを作る

中央kitをwrapperの土台としてcloneし、remoteを分離します。

[source,bash]
----
git clone https://dev.azure.com/<org>/<project>/_git/ai-dev-kit my-pkg-ai-dev
cd my-pkg-ai-dev

git remote rename origin upstream
git remote add origin https://dev.azure.com/<org>/<project>/_git/my-pkg-ai-dev
----

確認します。

[source,bash]
----
git remote -v
----

`origin`がwrapper、`upstream`が中央kitを指していることを確認してください。

[[getting-started-add-submodule]]
=== 3. 対象PKGを`src/`へ追加する

[source,bash]
----
git submodule add https://dev.azure.com/<org>/<project>/_git/my-pkg src
git submodule update --init --recursive
----

`src/`という配置はCLIの前提です。別名へ変更しないでください。対象PKGが入れ子のsubmoduleを持つ場合も`--recursive`を使用します。

[[getting-started-set-pat]]
=== 4. PATを現在のshellへ設定する

.PowerShell
[source,powershell]
----
$env:AZURE_DEVOPS_PAT = "<your-pat>"
----

.bash
[source,bash]
----
export AZURE_DEVOPS_PAT="<your-pat>"
----

PATは永続ファイルへ保存せず、組織のsecret管理方式に従って注入してください。`azure_devops.auth_env`を変更した場合は、その名前の環境変数を設定します。

[[getting-started-init]]
=== 5. wrapperを初期化する

最初に変更予定を確認し、その後に適用します。

[source,bash]
----
aidev init --dry-run
aidev init
----

`init`は主に次を行います。

. `aidev.yaml`を生成します。
. `templates/claude-assets/`から`.claude/`を実体化します。
. `CLAUDE.md`、`.mcp.json`を含むstatic assetのhashを`.aidev-lock`へ記録します。
. PAT環境変数、policy未作成、Wiki未作成などの次手順を案内します。

`init`はpolicyとWikiを自動生成しません。

非対話実行で推測できない値を明示する例です。

[source,bash]
----
aidev init --yes \
  --org <org> \
  --project <project> \
  --repository my-pkg \
  --wrapper-repository my-pkg-ai-dev
----

既存`.claude/`がkitと異なる場合、既定では上書きせずexit 2で停止します。`--force`はローカル内容を破棄し得るため、差分を退避して中央kitへ反映すべき内容がないことを確認した復旧時だけ使用します。

[[getting-started-configure]]
=== 6. `aidev.yaml`を調整する

最低限、generation targets、secret、Azure DevOps識別子、tracking branchを確認します。

[source,yaml]
----
version: 1
package:
  name: my-pkg
  include:
    - "src/src/**"
    - "src/docs/**"
  exclude:
    - "**/node_modules/**"
    - "**/generated/**"

secrets_paths:
  - "src/**/secrets/**"
  - "src/.env*"

azure_devops:
  organization: my-org
  project: my-project
  repository: my-pkg
  wrapper_repository: my-pkg-ai-dev
  auth_env: AZURE_DEVOPS_PAT

sync:
  tracking_branch: main
  auto_pr: true

knowledge:
  evidence:
    include:
      - "src/**"

model:
  agent: sonnet

quality_gates:
  lint: npm run lint
  test: npm test
----

初期値の`src/src/**`や`src/docs/**`がPKG構造に合わない場合は、Wiki生成前に修正します。`knowledge.evidence.include`は通常`src/**`のままとし、secretや生成物を除外します。全項目はxref:configuration[設定リファレンス]を参照してください。

[[getting-started-policy]]
=== 7. policyを生成・承認する

候補を生成します。

[source,bash]
----
aidev permission configure
----

`.aidev/policy.candidate.yaml`と現行設定をレビューします。問題がなければ承認します。

[source,bash]
----
aidev permission configure --approve
aidev permission show
----

承認済み`.aidev/policy.yaml`は保護対象です。直接編集せず、変更時は`aidev permission reconfigure`を使用します。保護を弱める変更は、レビュー後に`--approve --force`が必要です。

[[getting-started-knowledge]]
=== 8. LLM Wikiを生成する

proseを含む初回生成は次のとおりです。

[source,bash]
----
aidev knowledge build --agent
----

`--agent`を付けない場合は、manifest、inventory、checkpointなどのstructured stateだけを生成します。prose agentは実行時間と利用コストを伴うため、既定では無効です。

[source,bash]
----
aidev knowledge status
aidev knowledge build --refresh --agent
----

`claude` commandが見つからない場合でもstructured部分は残ります。`pending targets`を確認し、Claude Codeを利用できる環境で再実行します。

[[getting-started-verify]]
=== 9. 環境と整合性を確認する

[source,bash]
----
aidev doctor
aidev check
----

`doctor`はNode.js、Git、repository形状、submodule、remote、policy、PAT環境変数の存在、proxy、3SHAを診断します。Azure DevOps APIへの完全なlogin試験、Claude Code、`npx`の存在確認は行いません。

`check`はstatic drift、policy、3SHA、Wiki手編集を検査します。終了コードが0以外の場合はxref:troubleshooting[トラブルシューティング]に従って解消します。

[[getting-started-review-commit]]
=== 10. 生成物をレビューしてpushする

[source,bash]
----
git status --short
git diff

git add .gitmodules src aidev.yaml .claude .aidev-lock .aidev/policy.yaml knowledge
git commit -m "chore: initialize ai-dev-kit environment"
git push -u origin HEAD
----

[CAUTION]
====
`.aidev/policy.candidate.yaml`、`.aidev/cache/**`、task/lease、workflow run log、PATやsecretをcommitしないでください。`git status`とstaged diffを必ずレビューしてください。
====

[[getting-started-team-member]]
=== 既存wrapperへ参加する

2人目以降は中央kitではなく、作成済みwrapperをcloneします。

[source,bash]
----
git clone <my-pkg-ai-dev-url>
cd my-pkg-ai-dev
git submodule update --init --recursive
----

各自が別途xref:getting-started-install-cli[CLI専用checkoutをinstall]し、PATを自分のshellへ設定します。その後に確認します。

[source,bash]
----
aidev doctor
aidev check
claude
----

`.claude/settings.json`、Agents、Skills、hooksはClaude Codeのsession開始時に読み込まれます。`aidev init`または`aidev kit apply`の後はClaude Codeを再起動してください。
